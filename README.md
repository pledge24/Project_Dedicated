# Project_Dedicated

Top-Down 4-Player PvP — 언리얼 Dedicated Server + 자체 백엔드(매칭/인증/랭킹) 기반 랭킹 대전.

---

## Stack

- **Client / Dedicated Server**: Unreal Engine 5.7
- **Backend**: Node.js + Express + ws (WebSocket)
- **DB**: MySQL
- **Auth**: bcrypt + JWT

---
